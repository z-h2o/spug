# Spug 一键启动脚本使用指南

## 🎯 脚本概述

虽然 Spug 项目原本没有提供一键启动脚本，但我为你创建了一套完整的自动化管理脚本，让你可以轻松启动、停止和监控 Spug 服务。

## 📦 脚本文件说明

### 🚀 start-all.sh - 一键启动脚本
**功能**: 自动检查环境并启动所有 Spug 服务
**特点**: 
- 自动环境检查（Python、Redis、依赖等）
- 智能端口冲突处理
- 数据库状态验证
- 服务启动状态监控
- 详细的日志记录

### 🛑 stop-all.sh - 一键停止脚本
**功能**: 安全停止所有 Spug 服务
**特点**:
- 优雅停止所有服务进程
- 清理残留进程
- 释放端口占用
- 可选的日志文件清理

### 🔍 status.sh - 状态检查脚本
**功能**: 全面检查 Spug 服务状态
**特点**:
- 实时服务状态监控
- 系统资源使用情况
- 网络连接测试
- 日志文件分析
- 操作建议提示

## 🚀 快速使用

### 第一次使用
```bash
# 1. 进入项目目录
cd /Users/rui/Desktop/demo/spug/spug/spug_api

# 2. 确保脚本有执行权限（已自动设置）
ls -la *.sh

# 3. 一键启动
./start-all.sh
```

### 日常管理
```bash
# 启动所有服务
./start-all.sh

# 检查服务状态
./status.sh

# 停止所有服务
./stop-all.sh

# 简化状态检查
./status.sh --simple

# 持续监控模式
./status.sh --watch
```

## 🛠️ 高级用法

### 自动化部署
```bash
# 创建部署脚本
cat > deploy.sh << 'EOF'
#!/bin/bash
echo "开始部署 Spug..."

# 停止旧服务
./stop-all.sh

# 更新代码
git pull

# 安装依赖
source venv/bin/activate
pip install -r requirements.txt

# 数据库迁移
python manage.py migrate

# 启动服务
./start-all.sh

echo "部署完成！"
EOF

chmod +x deploy.sh
```

### 系统服务集成
```bash
# 创建 systemd 服务文件
sudo tee /etc/systemd/system/spug.service << EOF
[Unit]
Description=Spug Auto Platform
After=network.target redis.service

[Service]
Type=forking
User=spug
WorkingDirectory=/path/to/spug_api
ExecStart=/path/to/spug_api/start-all.sh
ExecStop=/path/to/spug_api/stop-all.sh
Restart=always

[Install]
WantedBy=multi-user.target
EOF

# 启用服务
sudo systemctl enable spug
sudo systemctl start spug
```

### 监控集成
```bash
# 与 Prometheus 集成的监控脚本
cat > prometheus_check.sh << 'EOF'
#!/bin/bash
# 输出 Prometheus 格式的指标

# 检查服务状态
for service in api ws worker scheduler monitor; do
    if ./status.sh --simple | grep -q "✅ $service"; then
        echo "spug_service_up{service=\"$service\"} 1"
    else
        echo "spug_service_up{service=\"$service\"} 0"
    fi
done
EOF
```

## 🐛 故障排除

### 常见问题

**1. Redis 连接失败**
```bash
# 检查 Redis 状态
redis-cli ping

# 启动 Redis
brew services start redis  # macOS
sudo systemctl start redis  # Linux
```

**2. 端口被占用**
```bash
# 查看端口占用
lsof -i :9001
lsof -i :9002

# 脚本会自动处理，或手动停止
./stop-all.sh
```

**3. 虚拟环境问题**
```bash
# 重新创建虚拟环境
rm -rf venv
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

**4. 权限问题**
```bash
# 确保脚本有执行权限
chmod +x *.sh

# 检查文件权限
ls -la *.sh
```

### 调试技巧

```bash
# 查看详细启动日志
./start-all.sh 2>&1 | tee startup.log

# 监控服务状态
watch -n 5 './status.sh --simple'

# 查看实时日志
tail -f logs/*.log

# 调试模式运行
bash -x ./start-all.sh
```

### 日志管理
```bash
# 设置日志轮转
cat > /etc/logrotate.d/spug << EOF
/path/to/spug_api/logs/*.log {
    daily
    rotate 30
    compress
    delaycompress
    missingok
    notifempty
    postrotate
        /path/to/spug_api/restart-logging.sh
    endscript
}
EOF
```
